# แผนสร้างเว็บขายไอดีเกม Roblox ครบระบบ

เว็บไซต์ขายไอดีเกม Roblox แบบครบวงจร ภาษาลาว ใช้สกุลเงินกีบ (₭) พร้อมระบบสมาชิก, เติมเงิน, ซื้อ-ขาย, และหลังบ้านแอดมินครบถ้วน

## เปิดใช้ Lovable Cloud
ต้องเปิด Lovable Cloud เพื่อเก็บข้อมูลผู้ใช้ / สินค้า / ออเดอร์ / เติมเงิน / สลิป / ข้อความ / การตั้งค่าเว็บ

## โครงสร้างหน้าเว็บ (หน้าลูกค้า)

**แถบบน (Header)** — ขนาดกลาง
- ซ้าย: โลโก้เว็บ (เปลี่ยนได้จากแอดมิน)
- ขวา: ยอดเงินกระเป๋า (₭ + ไอคอนกระเป๋า) + เมนู 3 ขีด

**เมนู 3 ขีด** (จากบนลงล่าง)
1. ข้อความ (มี badge สีแดงเมื่อมีข้อความใหม่)
2. โปรไฟล์ (เปลี่ยนชื่อ / เปลี่ยนรหัส)
3. ประวัติซื้อสินค้า
4. ประวัติเติมเงิน
5. เติมเงิน
6. จัดการแอดมิน (เฉพาะแอดมิน)
7. ออกจากระบบ (ปุ่มแดง)

**เนื้อหาหน้าหลัก**
- สไลด์รูปเดียว (ถ้ายังไม่มี → กรอบเส้นประ "ຍັງບໍ່ໄດ້ໃສ່")
- ช่องประกาศ marquee เลื่อนซ้าย + ไอคอนลำโพง
- หมวดหมู่สินค้า (การ์ดสี่เหลี่ยมแนวนอน รูปครึ่งซ้าย ชื่อขวา)
- สินค้าแนะนำ (grid) — ถ้าว่าง แสดง "ຍັງບໍ່ມີສິນຄ້າ"
- สินค้าบริการ (แยก section — ลูกค้ากรอกข้อมูลตอนซื้อ)
- สถิติ 4 บล็อก 2x2: สมาชิกทั้งหมด / ผู้เข้าชม / สินค้าพร้อมขาย / ขายแล้ว
- Top 3 คนเติมเงินสูงสุด (พร้อมจำนวนครั้ง)

**แถบล่าง (Bottom Nav)**
- กระเป๋า "ເຕີມເງິນ" | สินค้า | 🏠 หน้าหลัก | ประวัติ | ช่วยเหลือ

**โฆษณา Popup** — เด้งตอนเข้าเว็บ, ปุ่ม X / ปิด / ปิด 1 ชม.

## ระบบสมาชิก
- สมัคร: username / email / password / confirm password → popup สำเร็จเขียว
- Login: username หรือ email + password
- 1 อีเมล = 1 บัญชี
- อีเมล `glaos4993@gmail.com` = แอดมินอัตโนมัติ

## ระบบเติมเงิน
- **QR Code**: เลือกจำนวน (10k / 20k / 50k / 60k / 100k / 200k ₭ หรือกำหนดเอง) → สร้าง QR → แนบสลิป → ส่งแอดมินอนุมัติ
- **โค้ด**: กรอกโค้ด → เงินเข้ากระเป๋าทันที

## หลังบ้านแอดมิน
1. **สถิติ** — ผู้เข้าชม, ยอดเดือน (reset ทุกเดือน), รายได้
2. **ออเดอร์สินค้าทั่วไป** — ดูรายละเอียด
3. **ออเดอร์สินค้าบริการ** — ดูข้อมูลลูกค้ากรอก + ปุ่ม สำเร็จ/ปฏิเสธ/ส่งข้อความ (ปฏิเสธ = คืนเงินกระเป๋า)
4. **หมวดหมู่สินค้า** — เพิ่ม/แก้ (ชื่อ + รูป)
5. **เพิ่มสินค้าทั่วไป** — ชื่อ / ราคาลด / ราคาจริง (ขีดแดง) / รายละเอียด / รูป (upload หรือ link) / ซ่อนจากหน้าหลัก / ปุ่ม + เพิ่ม stock (ไอดีเกม)
6. **เพิ่มสินค้าบริการ** — เหมือนด้านบน + ช่องหมายเหตุให้ลูกค้ากรอก + ซ่อนจากหน้าหลัก
7. **ตั้งค่าเว็บ** (แบ่ง 6 จุด):
   - สี / โลโก้ / สไลด์ / QR Code / ลิงก์ติดต่อ (ช่วยเหลือ) / ชื่อเว็บ / ประกาศ / Discord webhook
8. **จัดการผู้ใช้** — list ผู้ใช้ + ปุ่มดู/แก้ไข (รหัส, ยอดกระเป๋า) / ลบ (ถังขยะแดง)
9. **อนุมัติเติมเงิน** — ดูสลิป + ปุ่มอนุมัติ/ปฏิเสธ
10. **โฆษณา** — อัปโหลดรูป + ลิงก์

## Popup ธุรกรรม
- สำเร็จ: ✓ เขียว + หัวข้อ "ສຳເລັດ" + รายละเอียด + ปุ่มฟ้า "ຕົກລົງ"
- ล้มเหลว: ✗ แดง + หัวข้อ "ລົ້ມເຫຼວ" + รายละเอียด + ปุ่มฟ้า "ຕົກລົງ"

## รายละเอียดเทคนิค
- **Frontend**: TanStack Start + Tailwind + shadcn/ui
- **Backend**: Lovable Cloud (Postgres + Auth + Storage)
- **Realtime**: badge ข้อความ, อนุมัติเติมเงิน
- **Tables**: profiles, user_roles, categories, products, product_stock, orders, service_orders, topups, messages, ads, site_settings, page_views
- **RLS**: user เห็นเฉพาะข้อมูลตนเอง, admin เห็นทุกอย่างผ่าน `has_role`
- **Storage buckets**: slips, product-images, site-assets
- **Discord webhook**: แจ้งเติมเงิน / ออเดอร์ใหม่

## ขอบเขต Turn แรก
งานใหญ่มาก — turn แรกจะ:
1. เปิด Lovable Cloud
2. สร้าง schema + RLS ครบ
3. สร้าง auth (สมัคร/login) + หน้าเว็บหลัก + bottom nav + header + สไลด์/ประกาศ/หมวดหมู่/สินค้า/สถิติ
4. เมนู 3 ขีด + โปรไฟล์ + ประวัติ + popup ธุรกรรม
5. หน้าเติมเงิน (QR + code) + แนบสลิป
6. หลังบ้านแอดมินครบทุก tab
7. โฆษณา popup

ถ้ามีจุดไหนต้องปรับหลังเห็นผล จะแก้ต่อได้เลย
